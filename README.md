# Nhà Mình

Cuốn sổ nhỏ của cả nhà: ghi việc trong ngày theo danh mục, kèm số tiền nếu có (đi chợ, hoá đơn, cúng rằm, thả cá…). Xem, sửa, xoá; tổng chi theo tháng. Dữ liệu nằm trên máy.

- Spec: `dev/specs/mvp.md`
- Design: mở `dev/design/index.html` trong trình duyệt
- Chạy app: `dev/guides/mobile-dev.md` (`pnpm install && pnpm mobile:android`)
- Quy ước cho người và AI: `CLAUDE.md`, `AGENTS.md`
